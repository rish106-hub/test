# F-007: Equity bridge: undefined cases

| Field | Value |
|---|---|
| Severity | minor |
| Owner | 00-main |
| Contract section | §3.1a, T-BNK-11..15 |
| Status | Open (reported 2026-10-25 by 05-qa) |

## Observation (expected vs actual)

1. `Forecast_Update_Flag` when no interim results exist (R = A): PASS, NOT RUN or blank? T-BNK-13 asserts only the deviation (None).
2. Deviation when the accrued forecast EPS(A, R] ≤ 0 (a loss year): the ratio is meaningless or divides by zero.
3. Interim periods that are not contiguous (Q2 reported, Q1 missing) or overlapping (Q1 and H1 both supplied): Σ EPS would
   miss or double-count a period, and the stub would start at R regardless.
4. Interim periods with a period end after V are ignored. That is implied by "(A, V]", but it should be stated.

## Reproduction / evidence

`test_I_CMP_05b_equity_bridge_ambiguity_flag_without_interims` records 02-valuation's choice; `test_I_CMP_05` compares the flag only where it is defined.

## Proposed resolution

Define flag = PASS (or NOT RUN) when R = A; deviation = None when the accrued forecast is ≤ 0; require contiguous, non-overlapping interims (raise otherwise).

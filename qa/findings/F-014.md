# F-014: Test-build watermark missing on VALIDATION_CHECKS

| Field | Value |
|---|---|
| Severity | minor |
| Owner | 00-main (build/main_sheets.py::_validation_checks) |
| Contract section | D-013, W-09b |
| Status | Open (reported 2026-10-25 by 05-qa) |

## Observation (expected vs actual)

`WorkbookContext._new_sheet` writes the "TEST BUILD - SYNTHETIC DATA" watermark to A1 of every sheet. `_validation_checks`
then writes "Executed checks only. NOT RUN is never shown as PASS." to the same cell, so VALIDATION_CHECKS in a test build
carries no synthetic watermark (D-013: "a test build watermarks every sheet").

## Reproduction / evidence

`tests/workbook/test_W_static.py::test_W_09b_*` (xfail, reported FAIL): unwatermarked sheets = ['VALIDATION_CHECKS'] in both the full and the `--only 03-nav` test builds.

## Proposed resolution

Write the VALIDATION_CHECKS caption to A2 (and shift the table), as the other 00-main sheets do.

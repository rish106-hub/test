# F-006: FV_Label strings are not exactly specified

| Field | Value |
|---|---|
| Severity | minor |
| Owner | 00-main |
| Contract section | §6 FV_Label |
| Status | Open (reported 2026-10-25 by 05-qa) |

## Observation (expected vs actual)

`"MANUALLY BIASED fair value (<bias>%)"` does not fix the number format (−10, −10.0, −10.00), and
`"Model output – fundamental case <case>"` uses an en dash (U+2013) that a builder may type as a hyphen. W-03 compares
Excel text with Python text exactly, so the format must be fixed. QA currently checks only the prefix for the manual label.

## Reproduction / evidence

`tests/independent/test_I_compare_workers.py::_label_ok`, `tests/workbook/test_W_values.py::_pc_compare`.

## Proposed resolution

Specify e.g. `TEXT(bias,"0.0%")` → `MANUALLY BIASED fair value (-10.0%)`, and state that the dash is U+2013.
